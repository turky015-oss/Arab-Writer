# وضع المستندات: قراءة PDF وتلخيصه وإخراجه

## 1. اقرأ قبل أن تلخّص

```
python3 scripts/pdf_extract.py file.pdf --info            عدد الصفحات وهل هو ممسوح ضوئياً
python3 scripts/pdf_extract.py file.pdf --out /tmp/raw.txt
python3 scripts/pdf_extract.py file.pdf --tables         الجداول وحدها
```

الملف الممسوح ضوئياً (نص مستخرج شبه صفر) يُحوَّل إلى صور وتُقرأ بصرياً:

```
python3 scripts/img_pdf.py to-img file.pdf /tmp/pages --dpi 200
```

لا تلخّص ملفاً لم تقرأ كل صفحاته. الملف الطويل يُقرأ على دفعات، لا بالعيّنة.

## 2. ما الذي يُنقل وما الذي يُحذف

يُنقل حرفياً بلا اجتهاد: الأرقام، النسب، المبالغ، التواريخ، المدد، الأسماء، أرقام المواد والبنود، الشروط الجزائية، الاستثناءات، التوقيعات والجهات، القرارات والتوصيات، المسؤول عن كل بند.

يُحذف: التكرار، الديباجة، عبارات المجاملة، الشرح الذي يخدم شكل المستند لا معناه.

الأقفال:
- لا تحذف رقماً ورد في الأصل. الرقم الذي لا يسعه الملخص يدخل جدولاً.
- لا تضف تفسيراً ولا رأياً ولا توصية لم ترد في الأصل.
- المصطلح يبقى كما ورد في المستند، ولو كان لك صيغة أفضل.
- العبارة المشروطة تبقى مشروطة: "قد" لا تصير "سوف"، و"يجوز" لا تصير "يجب".
- الغامض في الأصل يبقى غامضاً ويُشار إليه، ولا يُفسَّر.
- نسبة الملخص: من 10% إلى 20% من الأصل، وأقصر إذا كان الأصل حشواً.

## 3. هيكل الملخص

```
# عنوان المستند
سطر واحد: ما هذا المستند، من أصدره، متى.

## الخلاصة في سطور
ثلاثة إلى خمسة أسطر تكفي من يقرأها وحدها.

## المحاور
عنوان المحور، ثم فقرة أو نقاط بما فيه من أرقام وأسماء.

## الأرقام والتواريخ
| البند | القيمة | المصدر |

## القرارات والالتزامات
| البند | المسؤول | الموعد |

## ما يحتاج قراراً أو متابعة
نقاط قصيرة: الناقص، المتعارض، غير المحسوم.
```

المحاور تتبع المستند لا القالب. المستند الذي لا قرارات فيه لا يأخذ جدول قرارات.

## 4. النص العربي داخل الملخص

يمر بالمرحلتين 1 و2 قبل بناء الملف: بلا بصمة آلية، بلا إيموجي، بلا شرطة طويلة، إملاء ونحو مضبوط، والكلمة الإنجليزية في سطر مستقل.

## 5. بناء ملف PDF

```
python3 scripts/ar_pdf.py summary.md out.pdf \
  --title "ملخص التقرير" --subtitle "إعداد ..." \
  --logo logo.png --cover --footer "الجهة" --font amiri
```

| الخيار | متى |
|---|---|
| `--cover` | تقرير رسمي أو مستند يُرسل لجهة |
| `--logo` | وُجد شعار أو صورة يطلبها المستخدم |
| `--logo-width` | الشعار كبير أو صغير في المعاينة |
| `--font amiri` | الافتراضي، نسخي ويغطي كل الأشكال العربية |
| `--ltr` | المستند كله إنجليزي |
| `--footer` | اسم الجهة أو الحساب |

الشعار: اسأل عنه سؤالاً واحداً فقط عند توليد أي ملف PDF، ولا تكرره في الجلسة نفسها. لا شعار افتراضي ولا صورة مخترعة.

## 6. تحقق قبل التسليم

```
pdftoppm -png -r 70 out.pdf /tmp/chk       ثم افحص الصفحات بصرياً
```

الفحص البصري إلزامي في أول ملف بالجلسة: الحروف متصلة، الاتجاه من اليمين، لا مربعات فارغة، لا سطر خارج الهامش، الشعار في مكانه.

مربعات فارغة تعني خطاً لا يغطي أشكال العرض العربية. السكربت يتحول إلى Amiri تلقائياً، فإن بقيت المربعات فالخط المطلوب هو المشكلة لا النص.

## 7. حدّ معروف

النص داخل الملف المولَّد مرسوم بأشكال العرض العربية، فالنسخ منه أو البحث فيه يعطي حروفاً مقطّعة. المستخدم الذي يحتاج نصاً قابلاً للنسخ يأخذ ملف الماركداون المصدر مع الملف. لا تعِد بنص قابل للبحث داخل ملف PDF عربي.
