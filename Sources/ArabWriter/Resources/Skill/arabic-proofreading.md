# دليل التدقيق العربي

مرجع كامل للمرحلة 2. اقرأ القسم المتعلق بالخطأ الذي تشك فيه.

## 1. همزة القطع وهمزة الوصل

### تُكتب همزة القطع (أ / إ)
- الفعل الثلاثي المبدوء بهمزة ومصدره: أخذ، أكل، أمر، أمْر.
- الفعل الرباعي وأمره ومصدره: أكرم، أكرِم، إكرام / أنشأ، إنشاء / أرسل، إرسال.
- المضارع المبدوء بهمزة المتكلم: أكتب، أقول، أفهم.
- كل الأسماء ما عدا العشرة: أحمد، إبراهيم، أمّ، أب، أخ، إنسان، أمس، أين، أيّ.
- كل الحروف ما عدا "ال": إلى، إنّ، أنّ، أو، أم، إذا، إلا، إذْ، أمّا، ألا.

### تُكتب همزة الوصل (ا)
- "ال" التعريف: الكتاب، البيت.
- أمر الفعل الثلاثي: اكتب، اقرأ، اسمع، اذهب.
- ماضي وأمر ومصدر الخماسي: انتقل، انتقِل، انتقال / اجتمع، اجتماع / احترم، احترام.
- ماضي وأمر ومصدر السداسي: استخدم، استخدِم، استخدام / استفاد، استفادة / استغفر، استغفار.
- الأسماء العشرة: ابن، ابنة، اسم، امرؤ، امرأة، اثنان، اثنتان، ايمن الله، ابنم، است.

### الأخطاء الأكثر تكراراً
| خطأ | صواب |
|---|---|
| انشاء | إنشاء |
| إستخدام | استخدام |
| إنطلق | انطلق |
| إجتماع | اجتماع |
| الى | إلى |
| ان / انه | أن / أنه أو إن / إنه |
| اذا | إذا |
| اكثر | أكثر |
| افضل | أفضل |
| او | أو |
| اي | أي |
| امر | أمر |
| اعلان | إعلان |
| اضافة | إضافة |
| الاول | الأول |
| الان | الآن |
| اسم (صواب) | لا تكتب إسم |
| ابن (صواب) | لا تكتب إبن |

### قاعدة سريعة للتمييز
ضع "و" قبل الكلمة وانطقها. إن نُطقت الهمزة ("وأكرم") فهي قطع. إن سقطت ("وانتقل" تُنطق وَنْتقل) فهي وصل.

## 2. الهمزة المتوسطة
تُكتب على حرف يناسب أقوى الحركتين: حركتها وحركة ما قبلها. الترتيب من الأقوى: الكسرة (ياء/نبرة)، الضمة (واو)، الفتحة (ألف)، السكون.
- مسؤول (ضمة بعد سكون → واو)، لا مسئول.
- شؤون، رؤوس، مؤسسة، مؤتمر، يؤدي، مؤقت، فؤاد.
- سُئل، بيئة، رئيس، مبادئ (كسرة → نبرة)، جزئي، قائل، سائل، مسائل.
- سأل، رأى، كأس، مسألة، تأخر، تأثير (فتحة → ألف).
- قراءة، براءة، إجراءات، عباءة (بعد ألف مد → على السطر).
- تفاؤل، تساؤل، تشاؤم (همزة مضمومة بعد ألف مد → واو).
- مروءة، سموءل (همزة مفتوحة بعد واو مد → على السطر).

## 3. الهمزة المتطرفة
تتبع حركة ما قبلها فقط.
- بعد كسرة → ياء: قارئ، شاطئ، مبادئ، بادئ.
- بعد ضمة → واو: تباطُؤ، لؤلؤ، تكافؤ.
- بعد فتحة → ألف: بدأ، قرأ، ملجأ، نبأ، خطأ.
- بعد ساكن أو مد → على السطر: شيء، بطء، جزء، دفء، سماء، ضوء، هدوء، بناء، مساء.
- عند التنوين بالفتح: شيئاً، جزءاً، بناءً، خطأً.

## 4. التاء المربوطة والتاء المفتوحة والهاء
- تاء مربوطة (ة) إذا نُطقت هاءً عند الوقف وتاءً عند الوصل: مدرسة، تقنية، فكرة، مؤسسة، شركة، حديقة، معلمة.
- تاء مفتوحة (ت): في جمع المؤنث السالم (معلمات، شركات)، الفعل (كتبت، ذهبتْ)، الاسم الثلاثي الساكن الوسط (بنت، أخت، وقت، بيت)، الجمع الذي مفرده بتاء مفتوحة (أوقات، أصوات).
- هاء (ه): هذه، إليه، عليه، وجه، مياه، فقه، شبه، الله، انتباه، اتجاه.
- الاختبار: نطق الكلمة مع الوصل. "مدرسةُ الحي" (تاء) → مربوطة. "وجهُ الرجل" (هاء) → هاء.

| خطأ | صواب |
|---|---|
| تقنيه | تقنية |
| مدرسه | مدرسة |
| هذة | هذه |
| شركه | شركة |
| اليه | إليه |
| مياة | مياه |

## 5. الألف المقصورة والألف الممدودة والياء

### الألف اللينة في آخر الكلمة
- فعل ثلاثي أصله واو → ألف ممدودة: دعا (يدعو)، رجا، سما، غزا، عفا.
- فعل ثلاثي أصله ياء → مقصورة: سعى (يسعى)، بنى (يبني)، رمى، مشى، جرى.
- فوق الثلاثي → مقصورة إلا إذا سبقتها ياء: استدعى، تمنّى، اشترى، ألقى. وبالممدودة إذا سبقتها ياء: أحيا، استحيا، دنيا، قضايا.
- الفعل "يحيا" بالممدودة، والعلم "يحيى" بالمقصورة للتفريق بينهما.
- الأسماء الأعجمية → ممدودة: أوروبا، أمريكا، فرنسا، موسيقى (استثناء).
- الحروف → ممدودة: ما، لا، إلا، خلا، عدا. إلا: على، إلى، بلى، حتى.
- الأسماء المبنية → ممدودة: هذا، أنا، إذا. إلا: متى، أنّى، لدى.

### الاسم الثلاثي
أصله واو → ممدودة: عصا (عصوان)، رضا، ربا، خطا. أصله ياء → مقصورة: فتى (فتيان)، هدى، مدى، رحى. الاختبار: ثنِّ الاسم أو ردّه لجذره.

### ياء لا ألف
في، الذي، التي، علي (اسم العلم)، نبي، كرسي، وطني.

| خطأ | صواب |
|---|---|
| علي (بمعنى فوق) | على |
| الي | إلى |
| الذى / التى | الذي / التي |
| فى | في |
| مصطفي | مصطفى |
| متي | متى |

### الألف الفارقة
تُزاد بعد واو الجماعة في الفعل: كتبوا، لم يكتبوا، اكتبوا، ذهبوا.
لا تُزاد في: واو الأصل (يدعو، يرجو، يشكو)، جمع المذكر السالم المضاف (معلمو المدرسة)، الأسماء (أبو، ذو).

## 6. الضاد والظاء
| ضاد | ظاء |
|---|---|
| أيضاً، ضروري، غضب، حضر، ضغط، ضوء، مرض، أرض، بعض، رفض، عرض، ضحك | نظام، ملاحظة، ظهر، انتظر، لحظة، حظ، عظيم، ظرف، حفظ، محافظة، نظر، ظلّ |

كلمات يُخلط فيها: "الحظ" (النصيب) و"الحض" (التحريض)، "ناظر" و"ناضر"، "ظلّ" (بقي) و"ضلّ" (تاه).

## 7. التنوين
- تنوين الفتح يُكتب مع ألف زائدة: كتاباً، دائماً، أيضاً، شكراً، جداً، مثلاً.
- لا ألف بعد التاء المربوطة: مدرسةً، فكرةً. ولا بعد الهمزة على الألف: خطأً، ملجأً. ولا بعد الهمزة المسبوقة بألف: سماءً، بناءً.
- موقع التنوين: على الألف (دائماً) أو على الحرف قبلها (دائمًا). كلاهما مقبول؛ التزم واحداً في النص كله. الافتراضي في هذه المهارة: على الألف.

## 8. المسافات
- مسافة واحدة بين الكلمتين.
- لا مسافة قبل الفاصلة والنقطة وعلامة الاستفهام. مسافة واحدة بعدها.
- واو العطف تلتصق بما بعدها: "وقال"، "وبعدها"، "والشركة". لا "و قال".
- لا مسافة داخل الأقواس: (هكذا) لا ( هكذا ).
- الرقم يلتصق بالنسبة والعملة: 50% ، 100 ريال (مسافة بين الرقم والوحدة المكتوبة).
- الاختصار يلتصق بنقطته بلا مسافة: "د." و"م." و"ص."، ومسافة واحدة بعدها قبل الكلمة التالية: "د. خالد".

## 9. الترقيم العربي
| العلامة | الشكل الصحيح | الاستعمال |
|---|---|---|
| الفاصلة | ، | بين الجمل المعطوفة والمفردات |
| الفاصلة المنقوطة | ؛ | بين جملتين إحداهما سبب للأخرى |
| علامة الاستفهام | ؟ | بعد السؤال، لا تجمع مع نقطة |
| النقطتان | : | قبل القول والتفصيل |
| علامة التعجب | ! | باعتدال، واحدة لا ثلاث |
| الاقتباس | "..." أو «...» | التزم شكلاً واحداً |
| الشرطة | - | للجمل الاعتراضية باعتدال. لا شرطة طويلة (—) |

لا تكتب نقطة بعد كل عبارة قصيرة. الجملة التامة تنتهي بنقطة، والعبارة داخل الجملة بفاصلة.

## 10. أخطاء نحوية شائعة

### العدد
- 1 و2: يطابقان المعدود: رجل واحد، امرأة واحدة، رجلان اثنان.
- 3 إلى 9: يخالفان المعدود: ثلاثة رجال، ثلاث نساء، خمسة أيام، خمس سنوات.
- 11 و12: يطابقان: أحد عشر رجلاً، إحدى عشرة امرأة.
- 13 إلى 19: الجزء الأول يخالف والثاني يطابق: ثلاثة عشر رجلاً، ثلاث عشرة امرأة.
- العقود لا تتغير: عشرون رجلاً، عشرون امرأة.
- المعدود بعد 11 إلى 99 مفرد منصوب: عشرون يوماً، لا عشرون أيام.
- المعدود بعد 100 و1000 مفرد مجرور: مئة يوم، ألف ريال.

### الجمع والمثنى
- جمع المذكر السالم: المعلمون (رفع)، المعلمين (نصب وجر). "جاء المعلمون" لا "جاء المعلمين".
- المثنى: طالبان (رفع)، طالبين (نصب وجر).
- عند الإضافة تسقط النون: "معلمو المدرسة"، "طالبا الصف".

### الأفعال الخمسة
- ترفع بثبوت النون: "أنتم تكتبون".
- تُنصب وتُجزم بحذفها: "لم تكتبوا"، "لن يذهبوا"، "أن تفعلوا".
- الخطأ الشائع: "لم يكتبون" → "لم يكتبوا".

### الجزم بـ لم ولا الناهية
- صحيح الآخر: لم يكتبْ، لا تذهبْ.
- معتل الآخر: يُحذف حرف العلة: "لم يسعَ"، "لا تنسَ"، "لم يدعُ"، "لم يرمِ". الخطأ: "لا تنسى".

### إنّ وأخواتها وكان وأخواتها
- إن وأخواتها: تنصب الاسم: "إن الأمرَ مهم"، "لعل الخبرَ صحيح".
- كان وأخواتها: تنصب الخبر: "كان الجوُّ بارداً"، "أصبح الطريقُ مزدحماً".

### الأسماء الخمسة
- أبوك، أخوك، حموك، فوك، ذو مال (رفع). أباك، أخاك (نصب). أبيك، أخيك (جر).
- "قال أبوك" لا "قال أباك". "رأيت أباك" لا "رأيت أبوك".

### الإضافة
- لا "ال" على المضاف: "مدير المدرسة" لا "المدير المدرسة"، "وزارة الصحة" لا "الوزارة الصحة".
- المضاف إليه مجرور دائماً.

### أسماء الإشارة والموصول
- هذا / هذه / هذان / هاتان / هؤلاء (للعاقل جمعاً) / هذه (لجمع غير العاقل: "هذه الكتب").
- الذي / التي / اللذان / اللتان / الذين / اللاتي أو اللواتي.
- "هؤلاء الكتب" خطأ → "هذه الكتب".

### التذكير والتأنيث
- الفعل يؤنث مع الفاعل المؤنث: "قالت الوزارة"، "أعلنت الشركة"، "أصدرت الهيئة".
- الخطأ الشائع: "أعلن الشركة" → "أعلنت الشركة".
- جمع التكسير لغير العاقل يعامل معاملة المفردة المؤنثة: "الأجهزة جاهزة"، "السيارات توقفت".

### حروف الجر الشائعة
- "بحاجة إلى" لا "بحاجة لـ" في الفصحى.
- "يؤثر في" لا "يؤثر على".
- "يتكون من" لا "يتكون على".
- "عبارة عن" حشو غالباً، احذفها.
- "بالنسبة لـ" حشو غالباً، احذفها.

## 12. اللهجة السعودية/الخليجية المكتوبة
عند الكتابة بالعامية للمنشورات:
- الهمزات والتاء المربوطة والألف المقصورة تخضع لنفس قواعد الفصحى. "شفت الشركة" لا "شفت الشركه". "وش الى صار" خطأ → "وش اللي صار".
- الفاصلة العربية والترقيم العربي كما في الفصحى.
- الكلمات العامية المستقرة تُكتب بشكلها الشائع: "وش"، "ليه"، "كذا"، "أبغى" أو "أبي"، "الحين"، "زين"، "مو"، "ما".
- "إنت" و"أنت" كلاهما مقبول في العامية؛ التزم واحداً.
- اللام في "اللي" لامان.
- لا تخلط عامية وفصحى داخل فقرة واحدة.

## 13. القاموس
قبل تسليم أي نص، مرّر الكلمات المشكوك فيها على `references/arabic-dictionary.md`. يحوي الصيغة المعتمدة للمصطلحات التقنية وأسماء الشركات والمنتجات المعرَّبة، وقائمة الكلمات التي تُكتب خطأً في الاستعمال اليومي. الكلمة التي لا تجدها فيه: ردّها إلى جذرها وطبّق القواعد أعلاه، ولا تخمّن.
